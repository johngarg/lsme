* LSME: The one-loop dictionary for the linear SM extensions

=lsme= is a Python package that provides one-loop matching data for the linear
SM extensions: multiplets generating dimension-6 operators at tree level in the
Standard Model Effective Field Theory (SMEFT). The package is organised into two
submodules: one for retrieving numerical coefficients and another for searching
a symbolic database. The results presented here were calculated and compiled for
the research project "Mapping the one-loop structure of linear SM extensions"
([[https://arxiv.org/abs/2412.01759][arXiv:2412.01759]]).

* Installation

You can install the package via pip:

#+begin_src bash
pip install lsme
#+end_src

* Usage

** Numerical Coefficients

The =lsme.numeric= subpackage contains Python classes for each model, with methods that return numerical values for the matching coefficients of the B-conserving operators in the dimension-6 SMEFT.

Example:

#+begin_src python
from lsme.numeric import GranadaPi7MatchingResult as Pi7

# Create an instance of the model and compute a coefficient
# All massive params are in TeV, and initialised to 1 TeV
pi7 = Pi7()

# Coeffs are methods with the same name as you get from Matchmaker 
# Flavour indices are 0-initialised
coeff = pi7.alphaOdB(0,0)

# Return a dictionary of all coefficients, keyed by WCxf Warsaw names
# [arXiv:1712.05298] but in TeV units like the methods above
coeff_dict = pi7.coeff_dict()

# Return a WCxf object in GeV units, with the scale converted to GeV,
# e.g. for running with wilson
from wilson import Wilson
w = Wilson.from_wc(pi7.to_wcxf())
#+end_src

Do not pass =coeff_dict()= directly to =wilson= or other WCxf tools: WCxf
requires dimensionful coefficients and the scale in powers of GeV. Use
=to_wcxf()=, which converts dimension-six coefficients by \(10^{-6}\) and the
dimension-five Weinberg coefficients by \(10^{-3}\).

*** Barred parameters

Parameter names ending in =bar= denote complex conjugation. For matrix-valued
parameters, the flavour indices retain the same order; in particular,
\(\mathtt{ybar}_{ij} = (\mathtt{y}_{ij})^*\), not
\(\mathtt{ybar} = \mathtt{y}^\dagger\). Any transpose needed in a Hermitian
contraction is encoded by the explicit index ordering in the matching
expressions. Thus, for general complex Yukawa matrices, set the barred
parameters with component-wise conjugation:

#+begin_src python
pi7.yubar = pi7.yu.conjugate()
pi7.ydbar = pi7.yd.conjugate()
pi7.ylbar = pi7.yl.conjugate()
#+end_src

The default Yukawa matrices are real and diagonal, and the initialiser sets each
barred matrix to the conjugate of its unbarred counterpart, as a separate array.
The two are not kept in sync: users replacing or editing the unbarred defaults
with general complex matrices must also update the corresponding barred
parameters.

*** SM parameters at a scale

=lsme.numeric.sm_running= gives Wilson's pure-SM \(\overline{\mathrm{MS}}\)
parameters, evolved at one loop from \(M_Z\), at any scale from \(M_Z\) to
1000 TeV:

#+begin_src python
from lsme.numeric.sm_running import wilson_sm_lagrangian

sm = wilson_sm_lagrangian(5e4)  # scale in GeV
sm["gs"], sm["Lambda"], sm["Gu"]
#+end_src

The values are those Wilson extracts for an empty set of SMEFT coefficients,
=SMEFT(wcxf.WC("SMEFT", "Warsaw", mu, {})).C_in=, in Wilson's conventions and
GeV units: \(\mathcal{L} \supset m_2\,\phi^\dagger\phi -
\tfrac{\Lambda}{2}(\phi^\dagger\phi)^2 - (\bar q\,\Gamma_u u\,\tilde\phi +
\bar q\,\Gamma_d d\,\phi + \bar l\,\Gamma_e e\,\phi + \mathrm{h.c.})\), with
=Gu= carrying the CKM matrix in Wilson's down-aligned basis. They are not yet
mapped to LSME conventions or used by the matching classes.

A live Wilson extraction takes about 25 ms per scale and carries Wilson's
per-scale integration noise. The module instead evaluates a least-squares
Chebyshev fit in \(\ln\mu\), shipped as =lsme/numeric/data/sm_table.npz= and
loaded at import, so a lookup takes tens of microseconds and varies smoothly
with the scale. Its agreement with live Wilson extraction is limited by
Wilson's integration tolerance (about \(10^{-4}\) relative, \(10^{-3}\)
required), not by the fit. Scales outside \([M_Z, 1000\,\mathrm{TeV}]\) raise
=ValueError=.

The table records the Wilson version and a hash of Wilson's default SM inputs.
If either differs from the installed Wilson, or the file cannot be read, a
warning is issued and the table is rebuilt in memory (about 2 s); nothing is
written to disk. After upgrading Wilson, regenerate and commit the table:

#+begin_src sh
python scripts/build_sm_table.py
#+end_src

Above about \(10^9\) GeV Wilson's own extraction drifts from accurate one-loop
running because of its integration tolerance, and the one-loop Higgs quartic
changes sign near \(10^8\) GeV; the table therefore stops at 1000 TeV.

** Symbolic Database

The =lsme.symbolic= subpackage will provide a symbolic database that is searchable, allowing users to explore the matching data in a complementary way.  This is still under development.

* Submodules

- =lsme.numeric=: Contains models represented by classes whose methods return numerical matching coefficients.
- =lsme.symbolic=: A searchable symbolic database of the matching data.
